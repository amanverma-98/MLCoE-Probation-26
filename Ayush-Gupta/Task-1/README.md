# IPL Auction & Fantasy Match Simulator

## Overview
This project is a command-line simulator where a set of cricket players get auctioned to teams within a fixed budget, and the assembled squads then play a simulated match against each other[cite: 1]. It was built to enforce and demonstrate strict Object-Oriented Programming (OOP) principles in Python for the MLCOE society[cite: 1].

## Architecture & OOP Principles
*   **Abstraction:** The `Player` class acts as an Abstract Base Class enforcing an abstract `perform()` method for all child classes[cite: 1].
*   **Inheritance:** Subclasses including `Batsman`, `Bowler`, `AllRounder`, and a bonus `Captain` class inherit directly from the base `Player` framework[cite: 1].
*   **Polymorphism:** The match logic dynamically calls `perform()` identically across all player types, yielding distinct scoring behaviors per subclass without utilizing flat `if/elif` type-checking[cite: 1].
*   **Encapsulation:** The `Team` class strictly isolates the private `__budget` and `__squad` attributes, safely managing financial reductions through a `buy_player()` method that gracefully rejects unaffordable bids[cite: 1].

## Simulation Phases
*   **The Auction:** Orchestrates a live bidding loop for a pool of 10 players across two franchises, assigning randomized bids and validating purchases against encapsulated team funds[cite: 1].
*   **Squad Assembly:** Outputs the final purchased rosters and validates the remaining budget calculations for both teams[cite: 1].
*   **The Match:** Aggregates the polymorphic performance points generated by every player to declare the ultimate match winner[cite: 1].

## Installation & Usage
No external dependencies are required. Execute the script directly from your terminal using Python 3:

`python main.py`
